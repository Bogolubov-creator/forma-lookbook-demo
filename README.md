# Демо Forma

[Открыть демо гардероба и планера](https://bogolubov-creator.github.io/forma-lookbook-demo/)

В демо можно найти вещи из готовой коллекции, собрать образы и сохранить их на неделю. Вход не требуется. Планы хранятся в браузере. После первой полной загрузки демо доступно офлайн.

GitHub Pages публикует готовую сборку из ветки `main`. В репозитории хранятся файлы этой сборки и фотографии демоколлекции.
